## 第17周新增接口

```http
POST /api/composite-analysis
```

请求示例：

```json
{
  "county_ids": ["156420704", "156130626"],
  "start_year": 1980,
  "end_year": 2020
}
```

接口返回多个区县汇总后的土地利用面积、变化指数和转移矩阵。

## 第18周接口文档

```http
GET /api/docs
```

该接口返回后端核心API清单、参数说明和统一错误格式，供前端联调和课程文档整理使用。
